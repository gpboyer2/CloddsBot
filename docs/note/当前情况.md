## 一~九：为什么之前起不来

1. **项目根目录根本没有 .env 文件**（只有 .env.example），所有环境变量都是空的。
2. **启动时硬性校验 AI Key**（`src/index.ts` 第 118 行），没配就 `process.exit(1)` 直接退出——这不是"降级继续跑"，是一票否决。
3. **AI 大模型只认 Anthropic 官方**：核心 4 处 `new Anthropic({ apiKey })` 硬编码，没有中转站入口；你 codex 里那把 key（ai.939593.xyz）实测也被"无权访问 gpt-速刷 分组"挡死，所有模型都 403。
4. **~/.clodds/.env 里只有自动生成的凭证加密 Key**，没有别的东西，指望不上的第二个配置来源也是空的。
5. **Node 原生 fetch 根本不认 HTTPS_PROXY**：`.env` 里就算写了代理也是白写，项目 HTTP 层（`src/utils/http.ts`）从没装过代理，Polymarket / Kalshi / Binance 全部超时。
6. **没有配置任何消息通道**（Telegram / Discord 都没填），只有 WebChat 能用（这只是 WARN，不拦启动）。
7. **`.npmrc` 里 `ignore-scripts=true`**，装依赖时所有安装脚本都没跑：sharp / better-sqlite3 / bigint-buffer 的原生库没编译、本地向量模型没下载，所以启动时刷 "Failed to load transformers.js model" 和 "bigint: Failed to load bindings"。
8. **供应商探活写死了已停用模型**（claude-3-haiku-20240307），而且探活地址写死 api.anthropic.com，不认中转站，导致每 30 秒刷一条 "health check failing"。
9. **WebSocket 行情连接不走代理**：`ws` 库不经过 HTTP 层的代理，全项目 22 处 `new WebSocket` 没有统一入口，Polymarket 行情 WebSocket 直连超时（这个是遗留问题，见下文"残余风险"）。
